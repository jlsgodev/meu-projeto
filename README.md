## O que foi praticado

1. Configuração do Git (`git config`)
2. Repositório local (`git init`, `git branch -M main`)
3. Primeiro arquivo e primeiro commit (`git add`, `git commit`)
4. Repositório no GitHub e conexão (`git remote add origin`, `git push -u origin main`)
5. Branch de funcionalidade (`git switch -c feature/...`), commit e push da branch
6. Merge da branch na `main`
